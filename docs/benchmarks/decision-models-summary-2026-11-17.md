# LAYA · H2O · Gemma 종합 비교

2026-11-17 KST, 동일 TITAN RTX 24 GiB / Ryzen 5 5600 호스트의 실측입니다.

**현재 확인한 차이는 속도와 안정성입니다. 실제 한국어 구매 의향의 정답 정확도는 검증하지 않았습니다.** LAYA는 빠른 사전 선별 후보이고, H2O는 선택지 순서 안정성에서 장점이 관찰됐습니다. 최종 마케팅 승자를 자동 채택하는 용도로는 추가 검증이 필요합니다.

## 1. 전체 파이프라인과 직접 추론을 구분

같은 문구·페르소나·v2 구매 정의를 사용했습니다. 구매는 무료 체험 시작과 구분한 유료 지불 의향입니다. full 페르소나 1500자, 관심/클릭/구매/신뢰 가중치 0.25/0.25/0.35/0.15를 적용했습니다.

| 전체 파이프라인: 접수 → 검색 → 큐 → 리포트 | 시간 |
| --- | ---: |
| LAYA CUDA, 24명 | 16.114초 |
| 기존 Gemma/Ollama, 24명 | 88.995초 |

이 비교에서 LAYA는 약 5.52배 빨랐습니다. 수동 종합 분석은 제외했습니다. [Gemma 비교·사례 분석·원본 데이터](laya-vs-gemma-2026-11-17.md)에 실행 조건과 캐시 한계를 기록했습니다.

| 직접 추론: 검색·큐·초기 로딩 제외, 24명 | 시간 |
| --- | ---: |
| LAYA CUDA FP16, 질문 8개 배치 | 3.919초 |
| H2O Q8_0, 슬롯 1 / 클라이언트 1, 최초 비교 | 56.599초 |
| H2O Q8_0, 슬롯 8 / 클라이언트 8 | 14.016초 |

**배치 설정을 맞추면 H2O와 LAYA의 격차는 약 14.4배에서 3.58배로 줄었습니다.** 단일 슬롯의 시간을 H2O 모델의 최적 성능으로 해석하면 안 됩니다. 14.016초에 검색 시간을 더한 H2O 전체 시간을 실제 측정한 것은 아니므로, 이를 위의 16.114초와 직접 비교하지 않습니다.

## 2. H2O 배치 비교

운영 포트 8761은 유지하고 별도 포트 8762에서 같은 모델 파일·실행 파일을 사용했습니다. 각 서버는 순차 실행 후 종료했습니다. GPU 레이어 99, 총 context 40960, `--no-kv-unified`, batch 관련 나머지 기본값을 유지했습니다. 슬롯별 context는 40960/10240/5120으로 달라지지만 모든 입력이 그 안에 들어갔고 잘림은 없었습니다. 각 조건은 준비 요청 1건 후 24명 1회 측정했습니다.

| 서버 슬롯 | 클라이언트 동시성 | 시간 | 단일 슬롯 대비 winner 일치 | 최대 확률 차이 |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 1 | 56.183초 | 24/24 | 0 |
| 4 | 1 | 21.303초 | 24/24 | 1.654%p |
| 4 | 4 | 21.013초 | 23/24 | 1.323%p |
| 8 | 1 | 14.351초 | 24/24 | 1.021%p |
| 8 | 8 | 14.016초 | 24/24 | 0.932%p |

측정 범위에서 슬롯 8/클라이언트 8은 슬롯 1보다 4.01배 빨랐습니다. 전역 최적화나 지연 분포를 입증한 결과는 아닙니다. 슬롯 4/클라이언트 4에서는 경계 판정 한 건이 바뀌었으므로 확률까지 동일한 실행 방식으로 볼 수 없습니다. 단일 슬롯 재측정의 점수는 이전 24명 결과와 전부 일치했습니다.

LAYA는 321,908,998 파라미터의 FP16 autocast 경로, H2O는 4B급 Q8_0 llama.cpp 경로입니다. H2O 단일 슬롯에 같은 상태를 보내고 질문만 1/2/8개로 바꾸면 평균 0.149/0.289/1.187초(각 2회)가 걸렸습니다. 모델 규모와 실행 방식이 함께 다르므로 각 요인의 기여율은 분리하지 못했습니다.

## 3. 판정과 안정성

원래 H2O 단일 슬롯 비교에서 최종 추천은 LAYA A / H2O A / Gemma B였습니다. H2O와 LAYA의 표본별 winner 일치는 19/24(79.2%), H2O와 기존 Gemma는 13/24(54.2%), 최종 v2 LAYA와 Gemma는 8/24(33.3%)였습니다. 어느 모델도 정답 라벨로 사용하지 않았습니다.

| 성질 | LAYA | H2O 단일 슬롯 |
| --- | ---: | ---: |
| 같은 8명 재실행 점수 완전 일치 | 8/8 | 8/8 |
| 선택지 순서 변경 시 긍정 확률 평균 절대 차이 | 15.46%p | 2.12%p |
| 선택지 순서 변경 시 최대 차이 | 92.75%p | 7.36%p |

순서 차이는 24명 × 2개 안 × 4지표 = 192개에서 계산했습니다. 같은 입력의 반복 일관성과 선택지 순서에 대한 안정성은 다릅니다. 두 순서를 평균한 운영 점수가 반복 가능하더라도 내부 순서 민감도가 사라진 것은 아닙니다. 이 항목에서는 H2O의 장점이 관찰됐지만 정확도·확률 보정 성능을 입증한 것은 아닙니다.

## 4. 사례를 읽은 판단

다음은 검토자의 해석이며 실제 사용자 정답이 아닙니다.

- 꼼꼼하고 소득이 낮은 30대 개발자: LAYA/H2O A, Gemma B. H2O는 A 80.45 / B 79.35로 근소합니다. 무료 체험을 통한 검증이라는 해석은 가능하지만 실제 선호의 증거는 아닙니다.
- 신규 소프트웨어 도입에 보수적인 49세 편집자: 모두 B. H2O의 가중 점수는 A 61.65 / B 64.70, LAYA는 A 58.70 / B 80.40입니다. H2O의 격차는 작지만 구매 의도 자체는 A 75 / B 70으로 높아 변화 거부 성향을 충분히 반영했는지 의문입니다.
- 무탈한 정년을 중시하는 46세 사무 보조원: LAYA/H2O A, Gemma B. H2O는 A 59.00 / B 55.95로 낮고 근소한 차이를 냈습니다. 낮은 수치만으로 더 잘 보정됐다고 판단하지 않습니다.

초기 LAYA 어댑터는 구매를 이용 의향으로 묻는 문제가 있어 유료 지불 의향으로 수정했습니다. 이 보정만으로 6/24건의 winner가 바뀌었습니다. 모델을 고르기 전에 측정할 행동을 명확히 정의해야 합니다.

가격, 할인 유지 기간, 무료 체험 종료 후 결제·해지 조건, 신규/기존 고객 여부가 입력에 없습니다. 두 모델이 다른 가정을 세울 수 있습니다. **속도를 우선하면 LAYA, 선택지 순서 안정성을 우선하면 H2O를 추가 검토할 근거가 있습니다. 어느 쪽도 최종 마케팅 판단의 단독 기준으로 채택할 단계는 아닙니다.**
